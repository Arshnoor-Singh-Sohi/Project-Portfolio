Terms are in alphabetical order. "LITM" means [Lost in the Middle (2023)](/notes/papers/long-context/2023-lost-in-the-middle). "WRML" means [Why Reasoning Models Loop (2025)](/notes/papers/reasoning-models/2025-why-reasoning-models-loop). "PA" means [PagedAttention (2023)](/notes/papers/llm-serving/2023-pagedattention). "SGL" means [SGLang and RadixAttention (2023)](/notes/papers/llm-serving/2023-sglang-radixattention).

| Term | Plain meaning | First seen |
|---|---|---|
| # filled | The number of slots in a block that already hold the key and value of a token. | [PA 05](/notes/papers/llm-serving/2023-pagedattention/05-the-kv-cache-manager) |
| A10G | The NVIDIA GPU of AWS EC2 G5 instances, with 24 GB of memory. | [SGL 09](/notes/papers/llm-serving/2023-sglang-radixattention/09-results) |
| ablation | A test that changes one part of the method to see if the result still holds. | [WRML 07](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/07-results-looping-in-open-models) |
| acceptance test | A test that your code must pass before you call the exercise complete. | [WRML 14](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/14-reproduce-it) |
| accuracy | The percent of examples where any correct answer string appears in the output of the model. | [LITM 04](/notes/papers/long-context/2023-lost-in-the-middle/04-experiment-design) |
| action | One step of a reasoning chain. In the star graph, the choice of the next node. In a language model, a short chunk of tokens. | [WRML 01](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/01-background-probability-and-next-token-prediction) |
| activations | Temporary tensors that one forward pass creates and then discards. | [PA 03](/notes/papers/llm-serving/2023-pagedattention/03-the-question) |
| affinity | The preference to send a request to a worker that already holds its prefix. | [SGL 07](/notes/papers/llm-serving/2023-sglang-radixattention/07-frontend-hints-and-multi-gpu) |
| aging | A rule that raises a request's priority the longer it waits. | [SGL 06](/notes/papers/llm-serving/2023-sglang-radixattention/06-cache-aware-scheduling) |
| AIME | The American Invitational Mathematics Examination, a high-school math contest. Each paper has 15 problems, and each answer is a whole number. | [WRML 04](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/04-background-reasoning-models) |
| Algorithm 1 | The paper's scheduling loop with matching, sorting, admission, locking and eviction (Appendix A.2). | [SGL 06](/notes/papers/llm-serving/2023-sglang-radixattention/06-cache-aware-scheduling) |
| ALiBi | Attention with linear biases. It subtracts a penalty from each attention score. The penalty grows with the distance between the two tokens. | [LITM 02](/notes/papers/long-context/2023-lost-in-the-middle/02-background-attention-and-position) |
| all-or-nothing eviction | Evict all blocks of a sequence or none of them. | [PA 07](/notes/papers/llm-serving/2023-pagedattention/07-scheduling-and-preemption) |
| all-reduce | A collective operation: every GPU contributes a tensor and every GPU receives the sum. | [PA 07](/notes/papers/llm-serving/2023-pagedattention/07-scheduling-and-preemption) |
| allocation on demand | Giving a page a frame only when the program first uses that page. | [PA 01](/notes/papers/llm-serving/2023-pagedattention/01-background-virtual-memory-and-paging) |
| Alpaca | "an instruction dataset generated by GPT3.5 with self-instruct" (§6.1). Short inputs and short outputs. | [PA 09](/notes/papers/llm-serving/2023-pagedattention/09-results) |
| Amdahl's law | A speedup of one part of the work is limited by the share of that part in the total time. | [SGL 09](/notes/papers/llm-serving/2023-sglang-radixattention/09-results) |
| answer document | The one document in a prompt that contains the answer. | [LITM 04](/notes/papers/long-context/2023-lost-in-the-middle/04-experiment-design) |
| API speculative execution | For an API-only model: let the first call generate past its stop condition, and reuse the extra text for later primitives. | [SGL 08](/notes/papers/llm-serving/2023-sglang-radixattention/08-the-rest-of-sglang) |
| argmax | The position of the largest value in a list. The argmax of [0.53, 0.32, 0.12, 0.03] is position 1. | [WRML 02](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/02-background-decoding-greedy-temperature-sampling) |
| attention output | The weighted sum of the value vectors: $o_i = \sum_j a_{ij} v_j$. | [PA 04](/notes/papers/llm-serving/2023-pagedattention/04-pagedattention-the-algorithm) |
| attention score | The dot product of a query and a key, divided by $\sqrt{d}$. | [LITM 02](/notes/papers/long-context/2023-lost-in-the-middle/02-background-attention-and-position) |
| attention sink | A token, usually one of the first tokens, that gets strong attention whatever its meaning. | [LITM 10](/notes/papers/long-context/2023-lost-in-the-middle/10-limits-and-later-work) |
| attention state | The pair of a partial attention output and its LSE. Two states merge into the state of the union of their keys. | [SGL 11](/notes/papers/llm-serving/2023-sglang-radixattention/11-limits-and-later-work) |
| attention weight | The share of one value in the weighted average of attention. Weights are positive and add to 1. | [LITM 02](/notes/papers/long-context/2023-lost-in-the-middle/02-background-attention-and-position) |
| automatic prefix caching | vLLM's prefix cache with a hash chain over full blocks, released in vLLM 0.4.0. | [SGL 02](/notes/papers/llm-serving/2023-sglang-radixattention/02-background-prefix-sharing-in-lm-programs) |
| automatic prefix caching (APC) | vLLM keeps the KV blocks of finished requests and reuses them when a new prompt starts with the same tokens. | [PA 10](/notes/papers/llm-serving/2023-pagedattention/10-limits-and-later-work) |
| autoregressive generation | Writing one token at a time. Each new token joins the context. It stops at an end-of-sequence token or at a token budget. | [WRML 01](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/01-background-probability-and-next-token-prediction) |
| average cross-entropy | The training loss: the average of $-\log q(\text{correct action})$ over the training data. Lower is better. | [WRML 08](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/08-why-1-risk-aversion) |
| backtracking | A return to an earlier point of the solution, to try another way. | [WRML 04](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/04-background-reasoning-models) |
| base model | A model after pretraining only. It continues text. | [LITM 01](/notes/papers/long-context/2023-lost-in-the-middle/01-background-language-models) |
| baseline | An earlier system that the paper compares against. | [PA 09](/notes/papers/llm-serving/2023-pagedattention/09-results) |
| batch | The set of requests that the GPU processes together in one forward pass. | [PA 02](/notes/papers/llm-serving/2023-pagedattention/02-background-llm-serving-before-vllm) |
| batch size | The number of requests in a batch. | [PA 02](/notes/papers/llm-serving/2023-pagedattention/02-background-llm-serving-before-vllm) |
| batched requests | The number of requests that run together in one GPU step. | [PA 09](/notes/papers/llm-serving/2023-pagedattention/09-results) |
| beam search | Keep several best partial sequences at each step, ranked by log-probability. A search for one very likely text. | [WRML 02](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/02-background-decoding-greedy-temperature-sampling) |
| beam width $k$ | The number of candidates that beam search keeps after each step. | [PA 06](/notes/papers/llm-serving/2023-pagedattention/06-decoding-scenarios-and-sharing) |
| best case, worst case | The highest and the lowest accuracy over all tested positions. | [LITM 05](/notes/papers/long-context/2023-lost-in-the-middle/05-results-multi-document-qa) |
| best-of-k | Sample $k$ answers and keep a correct one. "The best-of-k version" of a model is this whole procedure, viewed as a new model. | [WRML 03](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/03-background-training-cross-entropy-and-distillation) |
| bidirectional | Each token can see the tokens before it and after it. | [LITM 02](/notes/papers/long-context/2023-lost-in-the-middle/02-background-attention-and-position) |
| block allocator | The object that gives a free physical block to a sequence and receives freed blocks again. | [PA 05](/notes/papers/llm-serving/2023-pagedattention/05-the-kv-cache-manager) |
| block engine | The part of a GPU worker that allocates one contiguous chunk of GPU DRAM and divides it into physical blocks. | [PA 05](/notes/papers/llm-serving/2023-pagedattention/05-the-kv-cache-manager) |
| block hash | A fingerprint of one full KV block, computed from the parent block's hash, the block's tokens and extra keys. | [PA 10](/notes/papers/llm-serving/2023-pagedattention/10-limits-and-later-work) |
| block size $B$ | The number of tokens per KV block. The paper's default is 16 (§7.2). | [PA 04](/notes/papers/llm-serving/2023-pagedattention/04-pagedattention-the-algorithm) |
| block table | The per-request list that maps each logical block to its physical block (page 05). | [PA 04](/notes/papers/llm-serving/2023-pagedattention/04-pagedattention-the-algorithm) |
| blowup | The response length of the learned model divided by the response length of the perfect learner. | [WRML 11](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/11-temperature-stopgap-or-cure) |
| branch | One copy after a `fork`. All branches start with the same prefix. | [SGL 07](/notes/papers/llm-serving/2023-sglang-radixattention/07-frontend-hints-and-multi-gpu) |
| buddy allocation | A memory allocator that hands out chunks whose size is a power of two. A request for 300 slots gets 512. | [PA 09](/notes/papers/llm-serving/2023-pagedattention/09-results) |
| byte | 8 bits. The smallest unit of memory that has its own address. | [PA 01](/notes/papers/llm-serving/2023-pagedattention/01-background-virtual-memory-and-paging) |
| cache engine | The part of a worker that holds the GPU and CPU KV blocks and performs swaps and copies. | [PA 08](/notes/papers/llm-serving/2023-pagedattention/08-implementation) |
| cache salt | A secret string in a request that puts its cache entries in a separate namespace. | [SGL 11](/notes/papers/llm-serving/2023-sglang-radixattention/11-limits-and-later-work) |
| cache threshold | The match rate above which the gateway prefers the worker with the cache. | [SGL 07](/notes/papers/llm-serving/2023-sglang-radixattention/07-frontend-hints-and-multi-gpu) |
| cache-aware routing | Sending a request to the replica that most likely holds its prefix in its radix tree. | [SGL 11](/notes/papers/llm-serving/2023-sglang-radixattention/11-limits-and-later-work) |
| cache-only model | Labs 3 and 4: the cache holds finished tokens only, at most $M$ of them. | [SGL 12](/notes/papers/llm-serving/2023-sglang-radixattention/12-reproduce-it) |
| `cache_salt` | A namespace string for isolation between tenants. It also changes the KV events and the storage keys. | [SGL 10](/notes/papers/llm-serving/2023-sglang-radixattention/10-radixattention-in-sglang-today) |
| candidate | One partial output of beam search. | [PA 06](/notes/papers/llm-serving/2023-pagedattention/06-decoding-scenarios-and-sharing) |
| cascade inference | FlashInfer's name for computing a shared prefix and the unique suffixes apart, then merging them by LSE. | [SGL 11](/notes/papers/llm-serving/2023-sglang-radixattention/11-limits-and-later-work) |
| catalyst | The paper's word for a force that does not start a loop, but makes a loop stronger and harder to leave. | [WRML 10](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/10-the-catalyst-growing-confidence) |
| causal attention | Attention in which a token sees only itself and earlier tokens. | [SGL 02](/notes/papers/llm-serving/2023-sglang-radixattention/02-background-prefix-sharing-in-lm-programs) |
| causal mask | A rule that stops each token from seeing the tokens after it. | [LITM 02](/notes/papers/long-context/2023-lost-in-the-middle/02-background-attention-and-position) |
| causal test | An experiment that changes one cause and measures the effect, with everything else fixed. | [WRML 13](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/13-limits-and-later-work) |
| chain of thought (CoT) | The intermediate steps that a model writes before its final answer. | [WRML 04](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/04-background-reasoning-models) |
| chain rule | The probability of a sequence is the product of the probability of each item, given the items before it. | [WRML 01](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/01-background-probability-and-next-token-prediction) |
| change-point detection | A method that finds the moment when a stream of numbers changes its behavior. | [WRML 13](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/13-limits-and-later-work) |
| Chatbot Arena | A public website where users chat with LLMs and compare them. The authors served models there with SGLang. | [SGL 09](/notes/papers/llm-serving/2023-sglang-radixattention/09-results) |
| checkpoint | The step that inserts the KV of a request into the tree and moves the request's lock to the new last node. | [SGL 10](/notes/papers/llm-serving/2023-sglang-radixattention/10-radixattention-in-sglang-today) |
| child key | The dictionary key under which a parent stores a child: the first token of the child's edge. | [SGL 01](/notes/papers/llm-serving/2023-sglang-radixattention/01-background-tries-and-radix-trees) |
| chunked prefill | Splitting a long prompt into chunks that run in several steps, together with decode tokens. | [PA 10](/notes/papers/llm-serving/2023-pagedattention/10-limits-and-later-work) |
| closed-book | A test setting with no documents. The model answers from parametric memory only. | [LITM 01](/notes/papers/long-context/2023-lost-in-the-middle/01-background-language-models) |
| coalesced memory access | Neighboring threads read neighboring addresses, so the GPU serves them with few wide memory transactions. | [PA 04](/notes/papers/llm-serving/2023-pagedattention/04-pagedattention-the-algorithm) |
| combined variant | The walk of Appendix D, where hardness and correlated errors act together. | [WRML 09](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/09-why-2-temporally-correlated-errors) |
| compaction | Replacing a long history in the context with a shorter summary. | [LITM 09](/notes/papers/long-context/2023-lost-in-the-middle/09-engineering-takeaways) |
| compressed edge | One edge that replaces a chain of singular transition edges and carries their whole string. | [SGL 08](/notes/papers/llm-serving/2023-sglang-radixattention/08-the-rest-of-sglang) |
| compute-bound | A step whose time is set by arithmetic, not by memory. More memory does not make it faster. | [PA 09](/notes/papers/llm-serving/2023-pagedattention/09-results) |
| conditional probability | $P(A \mid B)$: the probability of $A$ when we already know that $B$ is true. | [WRML 01](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/01-background-probability-and-next-token-prediction) |
| confidence | The top-1 probability. A confidence near 1 means that almost all probability is on one token. | [WRML 10](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/10-the-catalyst-growing-confidence) |
| confidence buildup | The rise of the top-1 probability toward 1 while the model repeats the same text (the title of Figure 15). | [WRML 10](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/10-the-catalyst-growing-confidence) |
| conjecture | A claim that the authors believe but leave for future work. | [WRML 13](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/13-limits-and-later-work) |
| consecutive-visit pair | Two visits to the root, one directly after the other, in the same trace. | [WRML 09](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/09-why-2-temporally-correlated-errors) |
| constraint | A rule that a solution must obey. Here: no probability is negative, and all probabilities add to 1. | [WRML 08](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/08-why-1-risk-aversion) |
| context | All the tokens that the model can use at one step. | [LITM 01](/notes/papers/long-context/2023-lost-in-the-middle/01-background-language-models) |
| context engineering | The design of what goes into the context of a model, in which order, and in which format. | [LITM 09](/notes/papers/long-context/2023-lost-in-the-middle/09-engineering-takeaways) |
| context rot | The drop in the reliability of a model as its input gets longer. | [LITM 10](/notes/papers/long-context/2023-lost-in-the-middle/10-limits-and-later-work) |
| context window | The largest number of tokens that a model can use at one time. | [LITM 01](/notes/papers/long-context/2023-lost-in-the-middle/01-background-language-models) |
| contextualization | The change of a token vector when it mixes in information from other tokens. | [LITM 02](/notes/papers/long-context/2023-lost-in-the-middle/02-background-attention-and-position) |
| contiguous | Next to each other with no gap. A contiguous region of memory is one unbroken run of addresses. | [PA 01](/notes/papers/llm-serving/2023-pagedattention/01-background-virtual-memory-and-paging) |
| contiguous chunk | One unbroken region of memory. Earlier systems stored each request's KV cache in one. | [PA 02](/notes/papers/llm-serving/2023-pagedattention/02-background-llm-serving-before-vllm) |
| continuation | Text that a model generates after a given prefix. | [WRML 07](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/07-results-looping-in-open-models) |
| continuous batching | Adding requests to the running batch and removing them from it at every iteration. | [SGL 03](/notes/papers/llm-serving/2023-sglang-radixattention/03-the-question) |
| Contriever | A neural retriever that ranks passages by vector similarity. In the paper, fine-tuned on MS-MARCO. | [LITM 04](/notes/papers/long-context/2023-lost-in-the-middle/04-experiment-design) |
| control message | The data that the scheduler sends to all workers at the start of each step. | [PA 07](/notes/papers/llm-serving/2023-pagedattention/07-scheduling-and-preemption) |
| control plane | The code that decides: scheduling, block allocation, preemption. In vLLM it is Python. | [PA 08](/notes/papers/llm-serving/2023-pagedattention/08-implementation) |
| controlled experiment | An experiment that changes one thing at a time and keeps all other things the same. | [LITM 03](/notes/papers/long-context/2023-lost-in-the-middle/03-the-question) |
| convex function | A function whose graph is never above a straight chord between two of its points. Each local minimum is a global minimum. | [WRML 08](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/08-why-1-risk-aversion) |
| copy-on-write | Two processes share one frame until one of them writes. Only then does the system make a private copy. | [PA 01](/notes/papers/llm-serving/2023-pagedattention/01-background-virtual-memory-and-paging) |
| cosine decay | A learning-rate schedule that falls from the start value to near zero along a half cosine curve. | [WRML 14](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/14-reproduce-it) |
| cost ratio $r$ | The time of one decode token divided by the time of one prefill token. A quantity of these notes. | [SGL 09](/notes/papers/llm-serving/2023-sglang-radixattention/09-results) |
| counter | A metric that only grows, for example the number of preemptions. Its exposed name ends with `_total`. | [PA 11](/notes/papers/llm-serving/2023-pagedattention/11-reproduce-it) |
| cross-entropy | The loss of next-token prediction. For one example it is $-\log q$, where $q$ is the probability that the model gave to the correct token. | [WRML 03](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/03-background-training-cross-entropy-and-distillation) |
| CUDA kernel | A function that runs on the GPU in many threads at once. | [PA 08](/notes/papers/llm-serving/2023-pagedattention/08-implementation) |
| CUDA virtual memory management | NVIDIA driver functions that reserve virtual addresses first and attach physical memory later. | [PA 10](/notes/papers/llm-serving/2023-pagedattention/10-limits-and-later-work) |
| curriculum | An order of the training examples, usually from easy to hard. | [WRML 11](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/11-temperature-stopgap-or-cure) |
| CUSUM | Cumulative sum: a change-point method that adds the excess of each new score over a reference value and raises an alarm above a threshold. | [WRML 13](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/13-limits-and-later-work) |
| cyclic action | An action that repeats something already done before, for example a restatement of a known fact. | [WRML 04](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/04-background-reasoning-models) |
| data parallelism (DP) | Several independent copies of the model. Each request runs on one copy. | [SGL 07](/notes/papers/llm-serving/2023-sglang-radixattention/07-frontend-hints-and-multi-gpu) |
| data plane | The code that touches the tensors: the model and the kernels on the GPU. | [PA 08](/notes/papers/llm-serving/2023-pagedattention/08-implementation) |
| decode | The second phase: the model generates one new token per iteration. The paper calls it the autoregressive generation phase. | [PA 02](/notes/papers/llm-serving/2023-pagedattention/02-background-llm-serving-before-vllm) |
| decode step | A later step. The model processes one new token per sequence. | [PA 05](/notes/papers/llm-serving/2023-pagedattention/05-the-kv-cache-manager) |
| decoder-only model | A model with only causal self-attention. | [LITM 02](/notes/papers/long-context/2023-lost-in-the-middle/02-background-attention-and-position) |
| decoding | The rule that chooses one token from the distribution of the model. It is separate from the model. | [WRML 02](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/02-background-decoding-greedy-temperature-sampling) |
| decoding step | One generated token. The plots of the paper call it a "time step". | [WRML 10](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/10-the-catalyst-growing-confidence) |
| delete a leaf | Remove a leaf from its parent's child map. Eviction (page 05) uses this operation. | [SGL 01](/notes/papers/llm-serving/2023-sglang-radixattention/01-background-tries-and-radix-trees) |
| delta | The change of the evictable size that a lock causes. It is 0 or negative. | [SGL 05](/notes/papers/llm-serving/2023-sglang-radixattention/05-eviction-and-reference-counts) |
| dependent variable | The thing that an experiment measures. | [LITM 03](/notes/papers/long-context/2023-lost-in-the-middle/03-the-question) |
| deterministic | Always gives the same output for the same input. No chance is involved. | [WRML 02](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/02-background-decoding-greedy-temperature-sampling) |
| deterministic algorithm | A procedure that always does the same steps for the same input. | [WRML 05](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/05-the-question) |
| DFS | Depth-first search: visit a tree by going as deep as possible before you return to an earlier node. | [SGL 06](/notes/papers/llm-serving/2023-sglang-radixattention/06-cache-aware-scheduling) |
| DFS order | An order of requests in which the requests below every node of the request tree form one contiguous block. | [SGL 06](/notes/papers/llm-serving/2023-sglang-radixattention/06-cache-aware-scheduling) |
| `dfs-weight` | SGLang's policy that orders the waiting queue by a depth-first walk of the cache tree, heaviest subtree first. | [SGL 06](/notes/papers/llm-serving/2023-sglang-radixattention/06-cache-aware-scheduling) |
| directed graph | A set of nodes and a set of edges. Each edge goes from one node to another node, in one direction. | [WRML 06](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/06-experiment-design) |
| distillation | Training a student model on the outputs of a teacher model. For the models in this paper: on the text that the teacher writes. | [WRML 03](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/03-background-training-cross-entropy-and-distillation) |
| distractor | A document that looks relevant but does not contain the answer. | [LITM 04](/notes/papers/long-context/2023-lost-in-the-middle/04-experiment-design) |
| easy problems | Per model, the 5 problems of each AIME paper with the highest accuracy at temperature 0.8. 20 in total. | [WRML 07](/notes/papers/reasoning-models/2025-why-reasoning-models-loop/07-results-looping-in-open-models) |
| edge | The run of tokens stored at a node: the tokens between its parent and itself. | [SGL 01](/notes/papers/llm-serving/2023-sglang-radixattention/01-background-tries-and-radix-trees) |
| edge ordering | An order that puts the most relevant documents at the start and at the end, and the least relevant in the middle. | [LITM 09](/notes/papers/long-context/2023-lost-in-the-middle/09-engineering-takeaways) |
