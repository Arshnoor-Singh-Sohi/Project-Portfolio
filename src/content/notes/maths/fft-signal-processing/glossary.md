| Term | Plain meaning | First seen |
|---|---|---|
| signal | A quantity that changes over time, for example air pressure or a voltage. | Course plan |
| sample | One measured value of a signal at one instant. A recording is a list of samples. | Diagnostic Q2 |
| pitch | How high a sound seems to a listener. For a simple tone, pitch follows the frequency. | Diagnostic Q2 |
| frequency | How many times a pattern repeats in one second. Full lesson: L2. | Diagnostic Q3 |
| amplitude | The height of the swing of a wave. Full lesson: L3. | Diagnostic Q3 |
| loudness | How strong a sound seems to a listener. It depends mainly on amplitude. The ear also hears some frequencies as louder than others. | Diagnostic Q3 |
| cycle | One full trip of a wave. It starts at a value and returns to the same value, moving in the same direction. One oscillation is one cycle. | L2 |
| period (T) | The time for one cycle. In a list of samples, you can also count it in samples. $T = 1/f$. | L2 |
| hertz (Hz) | The unit of frequency. 1 Hz is one cycle per second. | L2 |
| phase | Where a wave is in its cycle at the start. It does not change the frequency. Full lesson: L4. | Diagnostic Q5 |
| time step (Δt) | The time between two neighboring samples. A sample itself has no length. | L2 |
| sample rate ($f_s$) | The number of samples in one second. $\Delta t = 1/f_s$. Speech recognition often uses 16,000. | L2 |
