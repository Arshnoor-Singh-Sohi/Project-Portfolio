## How to use this page

1. The **corrections** table lists each handbook claim that a primary source contradicts. Each row links to the lesson that teaches the correct version.
2. The **sources** list gives the primary sources, part by part.
3. A correction enters this page only after a check against its primary source. The "Checked" column gives the date.
4. Handbook places use S for a session and Q for a FAQ question. For example, "S5 FAQ Q4" is Session 5, FAQ question 4.
