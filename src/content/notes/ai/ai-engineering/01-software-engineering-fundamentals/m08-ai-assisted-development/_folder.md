This module teaches you to work with a coding agent without losing control of the code. A coding agent can read, edit and run your project. That makes it fast and also risky. You learn the verification loop, project memory files, Skills, subagents, MCP, hooks and plugins. Every later level uses a coding agent, so these habits come first.

**Outcome:** you use a coding agent as a partner for exploring, building, debugging, refactoring and testing, with a plan before each meaningful change and verification after it.

**Before this module:** [M4 FastAPI services](/notes/ai/ai-engineering/01-software-engineering-fundamentals/m04-fastapi-services) (you need a service to change) and [M7 Git and collaboration](/notes/ai/ai-engineering/01-software-engineering-fundamentals/m07-git) (you need to read diffs).
