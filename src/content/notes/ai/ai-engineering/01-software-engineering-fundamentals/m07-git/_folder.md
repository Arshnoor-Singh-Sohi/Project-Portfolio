Git records every change to your code as a snapshot with a reason. You can see what changed, restore an old version, work on two things at once, and share the work with other people. A coding agent changes many files fast, and Git diffs are the main way to review those changes. This module teaches Git from zero, with real command output from a scratch repository.

**Outcome:** another developer can understand, run and contribute to your repository without you sitting next to them.

**Before this module:** none. Read [7.1](/notes/ai/ai-engineering/01-software-engineering-fundamentals/m07-git/l1-repositories-commits-and-branches) before your first local practice project, even if you study module 3 first.

## Facts and versions

The command outputs in these lessons come from scratch repositories in a sandbox, with Git 2.43.0, on 2026-10-19. Hashes such as `25a9e5d` change on every run, so your hashes will differ. The behavior is the same in later Git versions. The GitHub facts come from GitHub Docs, checked on 2026-10-19.
